# Instalaciones Roa S.L. - Página web

Web corporativa estática para Instalaciones Roa S.L.

## Qué incluye

- Página principal responsive.
- Logo real de la empresa (`logo-roa.jpg`) integrado en cabecera, portada y footer.
- Servicios de fontanería.
- Botones de llamada al fijo, llamada móvil y WhatsApp con los teléfonos actualizados.
- Formulario estático que prepara un mensaje de WhatsApp al móvil de contacto.
- Direcciones de las dos tiendas.
- Horario.
- Sección preparada para fotos reales de trabajos.
- SEO básico: título, descripción, robots.txt, sitemap.xml y datos estructurados JSON-LD.

## Cómo desplegar en Vercel

1. Crea un repositorio en GitHub llamado `instalaciones-roa`.
2. Sube todos los archivos de esta carpeta, no el ZIP.
3. Entra en Vercel.
4. Pulsa `Add New` → `Project`.
5. Importa el repositorio.
6. Déjalo como proyecto estático.
7. Pulsa `Deploy`.

## Importante para Google

Para que aparezca en Google de forma seria:

1. Compra o conecta un dominio propio, por ejemplo `instalacionesroa.es`.
2. En Vercel, ve a `Domains` y añade el dominio.
3. Cambia en estos archivos el dominio provisional por el dominio real:
   - `robots.txt`
   - `sitemap.xml`
   - el campo `url` del JSON-LD dentro de `index.html`
4. Da de alta o actualiza el Perfil de Empresa de Google.
5. Añade la web en Google Search Console.
6. Envía el sitemap en Search Console.
7. Añade fotos reales de tienda, trabajos y equipo.
